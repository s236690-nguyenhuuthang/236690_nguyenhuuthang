Nguyễn Hữu Thắng 236690 DH23TIN09

Mô tả:

Hệ thống quản lý nhân sự là ứng dụng Web được xây dựng nhằm hỗ trợ quản lý thông tin nhân viên trong doanh nghiệp.
Hệ thống sử dụng kiến trúc Frontend – Backend, giao tiếp thông qua REST API và lưu trữ dữ liệu trên MongoDB Atlas.

Công nghệ:
Frontend: React.
Backend: Node.js và Express.
Cơ sở dữ liệu: MongoDB Atlas.
Quản lý mã nguồn: Git và GitHub.
Đóng gói ứng dụng: Docker.
Lưu trữ Docker image: Docker Hub.
Triển khai ứng dụng: Render.
